# DMart Sales & Operations Analysis (Power BI Dashboard)

## Project Overview
This project is a Power BI dashboard built to analyze DMart retail performance across **Sales, Customers, Products/Pricing, and Operations/Payments**.  
The goal is to convert raw order-level data into **clear KPIs and business insights** to support decision-making.

## Objectives
- Track overall sales performance and trends
- Understand customer behavior and engagement
- Identify top categories/products and pricing impact
- Monitor operational metrics like delivery time and payment status

## Tools Used
- **Power BI**
- Power Query (data cleaning & transformation)
- DAX (measures for KPIs)

## Dataset
Order-level retail dataset containing fields like:
- Order ID, Order Date
- Category, Product
- Customer Age, Gender
- Payment Method, Payment Status
- Order Status, Delivery Days, Ship Mode, Shipping Charges
- MRP, Discount Price, Total Order Value, Clicks
